Use:
- React + Tailwind CSS frontend
- Node.js + Express backend
- PostgreSQL database
- Leaflet map with OpenStreetMap

System purpose:
Register every private house, commercial building, government office, and institution in Jimma City. Field users collect GPS coordinates and property data using a mobile-responsive web form. Admins manage and approve records using a web dashboard.
